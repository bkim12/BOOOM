## Benchmark experiments

This folder contains the benchmark experiments used to evaluate the performance of the proposed optimization method across five representative problems on the Stiefel manifold.
Each subfolder corresponds to one optimization problem and includes the code, problem setup, and experimental results for that benchmark.


The benchmark folders are: 

- **HeterQuadForm**  : heterogeneous quadratic form optimization
  
- **ICA** : independent component analysis

- **KohnSham** : reduced Kohn–Sham Rayleigh–Ritz optimization

- **LRSD** : low-rank and sparse decomposition

- **OJD** : orthogonal joint diagonalization
  
- **Varimax** : Varimax factor rotation
